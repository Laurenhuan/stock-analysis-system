## 遇到的问题与解决

- **问题**：本地 `src/data/` 还是占位符，Role 2 实现在 gitee 分支且未合并进 main。
  **解决**：`git fetch` 只读拉到临时目录验证接口，不修改数据获取层、不动工作区；等合并后再正式对接。
- **问题**：Sample CSV 只有 8 个基础字段 + `drawdown`，缺 `return / ma5 / ma20 / volatility_20d / volume_change`（Role 2 的公共指标）。
  **解决**：demo 脚本内临时计算并在 docstring 标注为 Role 2 Owner 职责；合并后用 `build_common_features` 替换。
- **问题**：导出的 Plotly HTML 图打不开。
  **解决**：文件约 4MB（内联 plotly.js），需在文件资源管理器双击用浏览器打开，聊天里的相对路径链接点不动。
- **问题**：全仓库测试因缺 scikit-learn 收集失败（Role 5 聚类模块依赖）。
  **解决**：安装 scikit-learn（requirements.txt 声明的依赖）后 69 个测试全绿。
- **问题**：组长把远程分支 rebase 并 force-update 后，本地分支与远程分叉：本地 `src/data/features.py` 还是占位符，demo 一 import 就失败；直接 reset 会丢掉本地 3 个过程记录 commit。
  **解决**：`git cherry` 确认 4 个功能 commit 与远程 patch-id 等价后，`git rebase --onto` 只重放过程记录 commit，无冲突；备份分支保底。
- **问题**：相关矩阵重叠校验中 `np.fill_diagonal(overlap.values, ...)` 报「underlying array is read-only」（pandas 矩阵乘法返回只读数组）。
  **解决**：改用 numpy 数组计算两两有效交易日数再包回 DataFrame。顺手发现并修复：选股后单股票的折线名变成「收盘价」丢失股票身份，改为保留 symbol 作为线名。
- **问题**：全仓测试 1 个失败——Role 2 数据层测试缺 `tushare` 库。
  **解决**：本地 `pip install tushare` 后 126 个测试全绿；已在 PR 回复中提示队友环境需装或由 Role 2 在 requirements 声明。
