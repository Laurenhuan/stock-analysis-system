## 昨日遗留问题的回答

老师昨日反馈的问题是「今日提交中最难的一步是什么？」。

最难的一步是实现 `build_eda_insights`（问题驱动的 EDA 结论），而不是算统计指标本身。难在三点：一是要把零散的统计结果组织成结构化结论，每条 insight 都要凑齐 category / title / finding / evidence / interpretation / caveat 六个字段；二是要覆盖 performance / risk / trend / correlation / data_quality 五类，并处理单股票 vs 多股票、并列值、全 NaN、相关性样本不足这些边界，稍不留神就会输出误导性结论（后来组长复审 #2 指出的「nan%」就是边界没处理干净）；三是每条结论都要带「仅描述历史区间、不构成投资建议」的免责声明，且不能出现买卖/推荐/持有的措辞。这部分是「把数据翻译成有证据、有解释、有保留意见的结论」，逻辑分支多、最易错，两轮组长复审都卡在这里。

## 遇到的问题与解决

- 组长复审 #2 指出：多股 return 全 NaN 时，「高收益伴随高波动」结论的证据出现「收益中位数 nan%」；且 3 只股票中仅 2 只有效时仍会输出 Spearman ρ=1.00 的误导结论。根因是合并累计收益与波动率后没有先剔除 NaN 股票。解决：在算中位数和 Spearman 前 `dropna(subset=["cumulative_return", "volatility"])`，空样本提前返回，Spearman 门槛按有效股票数判断，并用两条回归测试锁死这个边界。
