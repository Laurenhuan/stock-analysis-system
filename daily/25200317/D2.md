## 遇到的问题与解决

- **问题 1：Role 2 的 return 列第一行是 NaN**
  - `build_stock_profiles` 原来直接校验数值列，第一行 NaN 导致报错
  - 解决：在校验前先 `dropna(subset=["return", "drawdown"])`，去掉首行 NaN

- **问题 2：检查顺序导致测试用例失败**
  - 原来先检查时间区间一致性，后检查有效 return 数。测试数据中单只股票只有 1 个有效 return，但 dropna 后时间区间与其他股票不一致，先触发了区间检查
  - 解决：调整代码顺序，先检查每只股票有效 return 数，再检查时间区间一致性

- **问题 3：测试数据构造困难**
  - 需要构造"时间区间一致但有效 return 不足"的数据，多次调试才构造成功
  - 解决：让所有股票的 trade_date 完全一致，但某只股票的 return 列大部分为 NaN

- **问题 4：之前不确定是否需要手动 fetch Role 2 的代码**
  - 不合并 Role 2 分支就无法真正验证端到端链路
  - 解决：执行 `git merge origin/feat/data-foundation` 合并，写真实调用 `build_common_features()` 的测试
