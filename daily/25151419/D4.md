## 遇到的问题与解决

### 问题 1：NotRequired 在 Python 3.10 不可用
**卡点**：`from typing import NotRequired` 在 Python 3.10 报错，该类型在 3.11+ 才可用。
**解决**：改用 `from typing_extensions import NotRequired`，项目已有该依赖。

### 问题 2：ClassificationResult.__required_keys__ 测试失败
**卡点**：使用 `total=False` 后，所有字段都变成可选，导致契约稳定性测试失败。
**解决**：改用 `NotRequired` 标注新字段，保持原有 4 个字段为 required。更新测试为 `issubset` 检查。

### 问题 3：单类别测试数据构造
**卡点**：第一次构造的测试数据（前 80% 单调递增 + 后 20% 随机）未能触发单类别错误。
**解决**：改用全量单调递增价格（所有 return > 0，所有 label = 1），确保训练集只有单一类别。
