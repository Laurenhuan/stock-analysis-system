## 函数签名、必需列、返回类型与异常

### EDA（src/analysis/eda.py）

1. `describe_statistics(df, *, columns=("open","high","low","close","volume","amount","return")) -> DataFrame`
   - 必需列：`symbol`；返回以 symbol 为索引、(字段, 统计量) 双层列的 count/mean/std/min/max 表
   - 异常：`NoDataError`（空）、`DataValidationError`（非 DataFrame / 缺 symbol / 无可统计列）
2. `date_range_summary(df) -> DataFrame`
   - 必需列：`symbol`、`trade_date`；返回 symbol/start_date/end_date/n_rows
   - 异常：`NoDataError`、`DataValidationError`
3. `risk_return_summary(df) -> DataFrame`
   - 必需列：`symbol`、`return`、`volatility_20d`、`drawdown`
   - 返回 mean_return / volatility（volatility_20d 均值，不年化）/ max_drawdown（drawdown 最小值）
   - 异常：`NoDataError`、`DataValidationError`
4. `returns_comparison(df) -> DataFrame`
   - 必需列：`symbol`、`return`；返回 mean_return / cumulative_return / win_rate / std_return(ddof=1)
   - 异常：`NoDataError`、`DataValidationError`
5. `correlation_matrix(df, *, method="spearman") -> DataFrame`
   - 必需列：`symbol`、`trade_date`、`return`；pivot 成 trade_date×symbol 后按 method 求两两相关
   - 异常：`NoDataError`、`DataValidationError`、`InsufficientDataError`（<2 只股票）
6. `missing_values_summary(df) -> DataFrame`
   - 任意 DataFrame；返回每列 missing_count / missing_ratio；异常：`NoDataError`、`DataValidationError`

### 可视化（src/visualization/charts.py）

1. `plot_price(df, *, symbols=None, show_ma=False, ma_windows=(5,20), title=None) -> Figure`
   - 必需列：`trade_date`、`close`（多股时需 `symbol`）；异常：`NoDataError`、`DataValidationError`
2. `plot_returns_comparison(df, *, symbols=None, title=None) -> Figure`
   - 必需列：`trade_date`、`symbol`、`cumulative_return`；异常：`NoDataError`、`DataValidationError`
3. `plot_risk_comparison(df, *, symbols=None, title=None) -> Figure`
   - 必需列：`symbol`、`volatility`、`max_drawdown`；异常：`NoDataError`、`DataValidationError`
4. `plot_correlation_matrix(corr, *, title=None, decimals=2) -> Figure`
   - 输入：n×n 方阵（DataFrame 或数组）；异常：`DataValidationError`（非方阵/空）
5. `plot_confusion_matrix(cm, *, labels=("0","1"), title=None) -> Figure`
   - 输入：n×n 方阵；异常：`DataValidationError`
6. `plot_actual_vs_predicted(df, *, title=None) -> Figure`
   - 必需列：`y_true`、`y_pred`；异常：`NoDataError`、`DataValidationError`

以上函数均返回 `plotly.graph_objects.Figure`，不渲染、不落地。

## 相关系数热力图说明

- **行列顺序**：与输入相关矩阵的 index/columns 顺序一致（`correlation_matrix` 输出为 symbol 升序）。
- **固定色域**：`zmin=-1.0`、`zmax=1.0`。
- **以 0 为中心**：`colorscale="RdBu_r"` 发散色标，0 落在色带中央。
- **缺失值/样本不足**：相关系数由 pandas `corr(method="spearman")` 成对删除 NaN；<2 只股票由 `correlation_matrix` 抛 `InsufficientDataError`，不会进入热力图。
