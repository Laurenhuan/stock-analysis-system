---

## 我负责什么（30秒）

我在六人团队中负责 K-Means 聚类模块，具体做了两件事：

**第一件事：构建股票画像**

每只股票用 3 个特征来描述：
- **mean_return**（平均收益）：这段时间平均每天涨多少
- **volatility**（波动率）：涨跌幅大不大，也就是风险大不大
- **max_drawdown**（最大回撤）：最多亏过多少

这 3 个特征就是一只股票的"画像"。

**第二件事：K-Means 聚类**

用 K-Means 算法把所有股票按这 3 个特征分成 3 类，方便后续展示和分析。

---

## 输入和输出（30秒）

**输入**：Role 2 提供的行情数据，包含股票代码、交易日期、收盘价、日收益率、回撤等字段。

**输出**：聚类结果，包含：
- 每只股票被分到哪个类别（0、1、2 三类）
- 每个类别的中心点特征值

具体调用流程：

```
行情数据 → Role 2 处理 → 我的 build_stock_profiles → 我的 run_clustering → 聚类结果
```

---

## 技术亮点（40秒）

**1. 数据质量校验**

我加了 9 种校验规则：
- 输入必须是 DataFrame，不能是字符串或 None
- 必须有 symbol、return、drawdown 三列
- return 列不能有 NaN 或 inf
- 每只股票的有效 return 必须 ≥ 2 个
- 所有股票的时间区间必须一致
- 不能有重复的股票代码

这些校验保证了不会因为数据质量问题导致聚类出错。

**2. 标准化处理**

聚类前用 StandardScaler 把 3 个特征标准化，因为：
- mean_return 的范围可能是 -0.05 到 0.05
- volatility 的范围可能是 0 到 0.3
- max_drawdown 的范围可能是 -0.5 到 0

如果不标准化，波动率会主导聚类结果。标准化后每个特征权重相同。

**3. 可复现性**

设置 random_state=42，保证每次运行结果相同，方便调试和验证。
