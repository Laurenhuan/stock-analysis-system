# 证券金融数据分析与可视化系统立项报告

> 状态：课程初稿，随实现与反馈持续更新。

## 一、项目背景

A 股历史行情包含价格、成交量、收益和风险等多维信息。初学者直接阅读原始表格难以形成整体认识，手工完成清洗、统计、建模和图表又容易产生口径不一致、时间序列泄漏及结果无法复现等问题。本项目拟建立一个面向学习和课程演示的轻量系统，将标准数据链路、EDA、三类基础机器学习算法和 Streamlit 页面整合到同一工程中。

## 二、项目目标

1. 获取并清洗 A 股日线数据，形成统一字段、类型、单位、排序和唯一性约束。
2. 计算收益率、累计收益、移动平均、波动率、成交量变化和回撤等指标。
3. 通过 EDA 与 Plotly 图表支持单股票观察和多股票横向比较。
4. 使用 Decision Tree 完成次日涨跌分类，使用 Linear Regression 完成次日收益率回归，使用 K-Means 完成多股票画像聚类。
5. 通过 Service Layer 将数据与算法结果接入 Streamlit，提供可解释、可测试、可离线演示的页面。

## 三、用户与范围

主要用户为课程教师、项目成员和希望学习金融数据分析流程的同学。系统只做历史数据教学分析，不提供交易策略、实时行情、自动交易或投资建议。P0 不增加 Random Forest、LSTM 等扩展模型，先保证三种算法的数据切分、指标和展示完整。

## 四、技术路线

- Python、pandas、NumPy：数据处理和指标计算。
- scikit-learn：Decision Tree、Linear Regression、StandardScaler 和 K-Means。
- Plotly、Streamlit：交互式图表与多页面应用。
- pytest：Contract、单元和集成测试。
- Gitee：分支、PR、Review、课程扫描与材料提交；GitHub：备份镜像。

系统遵循 `UI → Service → Domain/Data` 的单向依赖。公共输入输出以 `docs/contracts/` 为准；无可用 Token 或网络时使用仓库内 Sample Data，保证演示可重复。

## 五、团队分工

六人分工及 Gitee 用户名见 README 和 `docs/role_boundaries.md`。Role 1 只负责集成，不代写各模块业务逻辑；Role 6 可进行算法 Review，但修改仍由对应 Owner 完成。

## 六、阶段计划

- D1：工程骨架、数据契约、Sample Data、集成原型和六人边界。
- D2：数据层接入与 EDA 最小实现。
- D3：分类、回归、聚类最小实现及时间序列切分检查。
- D4：三类算法指标、图表和页面联调。
- D5：集成测试、异常处理、结果解释和文档完善。
- D6：回归测试、演示准备、报告定稿和课程材料检查。

## 七、验收标准

应用可在无秘密信息的环境中启动；Sample Data 路径稳定；三种算法均提供约定指标和可解释输出；不存在明显未来信息泄漏；测试通过；README、todos、daily、prompts 和三个 Markdown 报告按课程要求持续更新。
